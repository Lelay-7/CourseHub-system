# 私聊验证记录

实现依据 `superpowers/specs/2026-10-11-private-chat-design.md` 和 `superpowers/plans/2026-10-11-private-chat.md`；正式 UI 使用原主题变量。实现位于隔离分支 `codex/private-chat`，未推送、未部署、未迁移业务数据库，也未配置真实 SMTP。

## 已执行的验证

- 基线：后端 153 项测试通过。
- 好友关系：真实 H2/MyBatis/事务与控制器 16 项测试通过，覆盖反向已接受、不合法目标、接收人条件接受、参与者删除及升序用户锁；联系人前端隐私和搜索竞态回归通过。
- 聊天服务与 API：成员隔离、管理员无额外权限、只读历史、重新加好友复用、最小 peer、字符串 ID、已读单调、TEXT Unicode、幂等、额度/消息/事件回滚及 HTTP 400/401/403/404/409/429 已执行聚焦验证。
- 前端：真实状态协调与请求模块覆盖原 UUID 重试、分页补拉与 BigInt、切换/退出迟到响应、可见底部读游标、Unicode、隐藏取消、无轮询重叠和 10/20/40/60 秒退避；认证覆盖刷新保持身份、退出同步清理及跨标签身份替换。
- UI fixture：生产构建的 Chromium 页面检查瓷白墨蓝、暖白酒红、曜石黑各 1440/768/390/320px，共 12 组合；另检查 IME Enter、Shift+Enter、HTML 字面显示、丢失响应原 UUID 重试、旧历史定位、新消息定位条、只读/空状态和缩小视口。管理员手机页单独检查提示条不会挤出发送区。此层使用限定 API fixture。
- 真实 MySQL：`verify-private-chat-mysql.ps1` 创建独立 MySQL 8/InnoDB/utf8mb4 实例。旧库来自提交 `f6ebb7c`，验证合法重复清理、非法数据无修改停止、当前 init + 迁移可重复、并发关系/创建/发送/读游标、删除和改密锁竞态、共享限流、回滚、过期清理与毫秒时间。每次 JUnit 均显式运行，不静默跳过。
- 真实浏览器：A/B 在真实 Spring Boot + MySQL 登录、申请/接受好友、发消息、接收/分页/未读、解除后只读、重新交友复用。非成员管理员 C 获得统一 404。改密后旧 A 的读取/发送/刷新拒绝，页面消息/草稿/未读清空。三主题真实 HTTP 数据显示通过，12 项验收通过，无浏览器异常或外部网络请求；私聊验收没有 SMTP。
- 共享脚本兼容性：默认账号恢复套件的 26 项 MySQL 测试，以及实际账号恢复浏览器 16 项验收通过；该回归仅使用本机临时邮件接收器。
- Schema 合同：28 张 mapper 表、3 个 SQL 文件及规范用户对/消息幂等索引检查通过。

最终完整后端回归为 175 项，零失败、零跳过；前端认证/找回/私聊状态共 28 项及两套契约、联系人回归、生产构建通过。私聊真实 MySQL 为 15 项，运行 ID `d9bc96d92d1e497b95d969b5162b2702`；最终真实浏览器运行 ID `fe4fb2b431b24d2aae12b728883b8847`，12 项通过并完成自建进程清理。

## 证据与修复

2026-10-11 的临时验收记录保存在被 Git 忽略的 `backend/target/coursehub-*-mysql-*`；浏览器截图和 JSON summary 在 `frontend/output/playwright/private-chat-*`。每次实例核对本次绝对数据路径、MySQL 8、端口、PID 文件、进程句柄与启动时间，fixture 再核对 nonce。成功和脚本失败路径均执行专属实例清理，测试证据保留。

首发时间曾保留纳秒而重试读取 `DATETIME(3)`，固定时钟测试先失败，随后将写入/响应统一到 UTC 毫秒；H2 和真 MySQL 回归覆盖相同消息完整 DTO。管理员手机提示条曾增加顶部占用，浏览器视口测试先失败，随后用导航栏实际底边计算剩余高度。

## 实际局限

浏览器模拟了视口缩小，未在真实 iOS/Android 设备实测软键盘和安全区。首版为 REST 轮询与 TEXT 私聊；附件、群聊、在线/输入状态和可靠跨实例推送属于后续设计。提交后进程内事件没有可靠投递保证。Vite 保留项目既有大 chunk 提示。

迁移与回退说明见 `../deploy/private-chat.md`。本次仅交付代码、局部环境验证和文档；业务库维护窗口与部署是后续运维操作。
