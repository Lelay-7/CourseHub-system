# 本机演示指南

网页整体体验已经确认完成。本指南用于在当前电脑上连续演示核心流程，约 8–10 分钟；每次演示不需要重新执行完整功能清单。

## 打开与结束

在本项目根目录使用以下入口：

| 文件 | 用途 |
| --- | --- |
| `start-local-demo.cmd` | 启动本机演示；已有环境运行时复用，首次启动等待服务健康后再打开网页 |
| `local-demo-status.cmd` | 查看演示环境当前状态 |
| `stop-local-demo.cmd` | 演示结束后停止服务，保留数据 |
| `backup-local-demo.cmd` | 环境运行时保存新的本机备份；先暂停页面上的编辑与提交，且源码须已提交 |

这些入口供**当前电脑**使用，依赖本机已准备好的运行环境与构建产物，并非可拷贝到其他电脑直接安装的便携包；无需修改全局 PowerShell 执行策略。

- 网页：[http://localhost:3001](http://localhost:3001)
- 本地测试收件箱：[http://localhost:3002](http://localhost:3002)

若启动提示端口占用或健康检查失败，先查看状态和启动窗口提示，不要关闭不明进程，也不要自行重置数据库。具体环境说明见 [本地产品体验环境](../scripts/product-preview/README.md)。

## 账号与演示准备

| 角色 | 账号 | 本次用途 |
| --- | --- | --- |
| 学生 A | `product_student_a` | 课程、资料重提、兑换订单、设置 |
| 学生 B | `product_student_b` | 可选的双账号私聊与资料查看 |
| 教师 | `product_teacher` | 备用：展示教师名片及职称、办公室字段 |
| 管理员 | `product_admin` | 资料审核、订单交付说明 |

四个账号的**初始密码**均为 `Product-local-2026!`。如之前已改密，请用修改后的密码；初始找回邮箱为 `账号名@example.test`，验证码在本地测试收件箱查看。新绑定邮箱也应使用未占用的 `@example.test` 地址。

建议学生 A 使用一个浏览器，管理员使用另一浏览器或独立浏览器配置，演示时切换窗口即可。同一浏览器的普通标签页共享登录，在其中一个标签页切换账号会影响其他标签页。若只用一个窗口，就按顺序退出并切换账号。

开始前花一分钟确认学生 A 当前余额、一份可演示的资料及可兑换商品。账号、资料和订单会沿用之前的操作结果：初始资料 `1000` 曾为 A 的驳回资料、`1001` 曾为待审第 2 版，**实际以当前页面状态为准**。没有合适的驳回资料时，准备一份无敏感内容的小文件，走下表中的新上传分支。无需为演示恢复全部种子数据。

项目的 `demo-assets/` 已附两份可直接选取的文本素材：上传用“课程学习提纲-V1.txt”，管理员填写“请补充复习步骤和练习说明”后驳回；重提时替换为“课程学习提纲-V2.txt”。管理员可以对照两版内容展示修改结果。

## 约 8–10 分钟的连续顺序

| 时间 | 演示步骤 | 讲解重点 |
| --- | --- | --- |
| 0:00–1:30 | 学生 A 登录，进入“课程” `/course`，搜索并打开一门课程，展示课程资料、讨论和教师入口；选择课程后到“我的选课” `/profile/courses` 回看。已有选课可直接展示。 | 课程信息与个人学习清单相互关联；这是学习辅助清单。 |
| 1:30–4:30 | A 从“我的上传” `/material?tab=my` 打开一份当前已驳回资料，查看原因，点“修改重提”，调整说明或替换文件并提交。切到管理员“资料审核” `/admin/materials`，打开同一资料，检查当前文件、版本与审核历史后通过；回 A 的详情查看已发布结果。若没有已驳回资料：A 先新上传，管理员填写具体原因驳回，再接上述重提流程。 | 驳回意见可回看，修改产生新版本，管理员针对当前版本审核，历史保留。使用现有驳回记录时，先展示已有驳回原因即可。 |
| 4:30–7:30 | A 到“积分商城” `/mall` 查看一件库存、积分与限制合适的商品，兑换后打开“我的订单” `/profile/orders`，记住新订单号。管理员到“订单管理” `/admin/orders` 找到该订单，打开“详情与处理”，填写用户可见的交付说明并确认完成；回 A 刷新该订单详情，展示状态和说明。 | 兑换、管理员处理、用户回看形成连续结果。说明可写“本地演示：展示领取安排，不实际发货”。若已有待处理演示订单，可直接复用。 |
| 7:30–9:00 | A 打开“设置” `/profile/settings` 的“界面与显示”，依次展示六套主题，选一套后刷新页面。 | 瓷白墨蓝、暖白酒红、曜石黑、雾青竹影、暮山浅紫、深海夜航；选择即时生效并保存在当前浏览器。 |

资料需新上传并驳回时，为资料步骤多留约一分钟；课程部分可只展示已有选课，商城也可复用已有待处理订单。演示以页面当前数据为准，不为凑流程修改既有正常资料或订单。

有余裕时可再用 1–2 分钟展示双账号私聊：让学生 B 在独立浏览器或配置中登录，从通讯录找到 A；若尚非好友，先完成申请与接受，再进入“消息” `/messages` 互发一条演示文字并回看会话。此步骤可选，不影响主线演示。

## 演示后与范围

关闭网页不会停止服务；需要结束运行时使用 `stop-local-demo.cmd`。上传、审核、选课、兑换、聊天、改密等数据在停止和再次启动后仍保留，主题保存在当前浏览器。不要通过删除数据目录或重新初始化数据库来恢复演示；如需恢复，使用已准备的本地备份并先核对备份说明。

备份目录为项目内 `.demo-backups/`，`latest.json` 指向最近一份完成备份。每份包含数据库 `demo.sql`、代码历史 `source.bundle`、构建/上传文件/收件箱/本地配置 `runtime.zip` 和带 SHA-256 的 `manifest.json`。备份只在本机保存，不进入 Git，包含本地账号配置；它不等于已验证的灾难恢复方案。恢复需同时核对代码版本、数据库、上传文件和数据库用户权限，由维护者处理，当前不提供一键重置或跨电脑安装。

当前演示只运行在本机。课程清单不代表正式教务选课，兑换品与交付说明不产生实际物流或发券；收件箱仅接收本地测试邮件，不投递外部邮箱。正式教务、完整物流、外部邮件和线上发布部署不在本次范围。

本指南描述操作方法，不作为当日服务运行或业务验证通过的记录。
