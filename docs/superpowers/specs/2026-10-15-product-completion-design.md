## 目标与边界

修正审视报告中的 F01–F14 和相关状态不一致；补齐资料审核、驳回修正、关联跳转、举报结果和兑换处理说明；保留三主题与现有技术栈，调整重点页面的信息结构。让用户能找到入口、完成操作、知道结果、刷新后保持一致、失败后继续操作，并让管理员可以接手需人工处理的事项。

- 现有好友/私聊和账号恢复是已完成基线，保持权限、幂等、身份清理、未读和键盘行为；只做必要联动与回归。
- 本轮必要新增入口是审核详情、驳回资料编辑/换文件、举报结果回看和订单处理说明；不扩建群聊、附件聊天、正式教务选课、教师独立工作台、平台通知系统或完整物流系统。
- 课程仍按学习辅助清单处理，页面说明不替代学校正式选课。教师继续使用现有权限；管理员维护课程。与旧需求文档不同之处记入范围表。
- 未实现的评分排序、通知偏好、签到/课时/分享奖励不继续表现为可用功能；后续是否新增由用户网页端体验后决定。
- 不部署、不改业务数据库、不配置真实 SMTP。测试和体验均使用有归属校验的独立数据库；密码恢复体验使用本地测试收件箱，真实邮件到达另列部署前事项。

## 设置页核实与决定

当前 `SettingsView.vue`、`EditProfileView.vue`、`ThemeOptions.vue`、`storage.js` 的行为已重新核实：

| 当前问题 | 设计决定 |
| --- | --- |
| 设置页隐私手动保存，编辑资料页相同选项立即保存 | 隐私只有一个编辑入口：设置页；编辑资料页用“管理通讯录隐私”链接进入该区域 |
| 主题立即生效，底部却有覆盖全页语义的“保存设置” | 主题标记为当前浏览器立即生效；仅隐私区域出现“保存隐私设置” |
| 通知开关仅存本地，没有业务消费 | 去掉无效交互项；保持既有消息中心入口，不新建通知偏好或展示技术占位说明 |
| 缓存大小把令牌、资料和主题等都统计进去，清缓存退出登录 | 当前没有可独立识别的大量持久缓存，移除误导性缓存容量和全量清除；维护动作改为准确的“重新加载页面”，保留登录和主题 |
| 总可见范围与手机号/邮箱开关存在父子关系，但界面没有充分表达 | 先选择名片详细信息的受众，再设置手机号/邮箱。在“仅自己”时字段对外均不可见，字段开关显示不可操作及原因，保留原选择以便切回 |
| 设置与资料、安全、帮助各自孤立 | 由设置页组织入口，资料编辑和安全表单仍放各自页面，避免重复表单 |

设置页结构：

1. **账号与安全**：只读登录账号、编辑个人资料入口、账号安全入口；找回邮箱只显示受控的绑定状态摘要，密码和邮箱验证仍在账号安全页完成。联系邮箱与已验证找回邮箱明确区分。
2. **隐私与可见性**：受众选择、手机号和邮箱的下级选项、当前有效范围摘要、独立保存与放弃未保存修改。公开基本名片与受限详细资料的说明遵守 `ContactCardPolicy`，不能暗示“仅自己”会隐藏所有基本信息。
3. **界面与显示**：三套主题的紧凑预览、当前选中标记、立即生效提示；使用现有主题变量，分别验证选中、焦点和禁用状态。
4. **帮助与页面维护**：反馈与举报、帮助/关于、版本、重新加载页面。服务联系方式使用统一配置；不写未经确认的服务时段或不同客服邮箱。

桌面使用清晰的分区目录与内容区；窄屏使用有标题的单列分区和紧凑设置行，不堆叠大型宣传卡。保留直接进入隐私区域的定位链接。

交互约定：

- 隐私初始加载失败时显示重试并禁用编辑；没有改动时保存禁用；保存成功后更新基线，失败保留修改，不能显示成功。
- 离开有未保存隐私修改的页面时提示放弃或留在页面；认证失效或主动退出不被该提示阻挡，不保留其他账号的数据。
- 主题切换不会保存隐私草稿；隐私保存不会重置主题。修改和保存期间均校验所属账号，迟到响应不能写入另一个账号。
- “重新加载页面”有明确说明，存在未保存修改时先处理；不执行 `localStorage.clear()`。浏览器刷新本身可能使内存中的未提交内容消失，因此不承诺保留所有草稿。

## 确定问题与业务闭环

### 列表与数据正确性

- 修正课程/Banner 编辑取消后新增保留旧 ID；新增和编辑的开关都先初始化表单。
- 积分、订单翻页与筛选重置分开；管理端接通完整 `list/total` 分页、筛选、错误和重试，不能固定只查首批。
- 课程、资料、广场查询只接受当前查询的响应；返回详情前的列表时保留筛选、页码和滚动，但不跨账号复用私人状态。
- 课程资料链接使用 `courseId`，讨论使用稳定课程标识；资料公开上传者用昵称等允许公开的字段，收藏状态按当前登录人计算。
- 资料移除无对应规则的评分排序；商城由服务端在全量排序后分页，保留“最新”和“积分从低到高”，暂不展示没有实际指标的热度排序。
- 课程代码继续全表保留唯一性；包含已删除记录的代码不能悄悄复用，查重和唯一键冲突给出可理解的提示，不新增课程恢复系统。
- 退款使用服务端余额更新本地状态。个人中心统计由后端按月汇总，`earned` 为奖励、`spent` 为消耗、`refunded` 为退款；退款不冒充奖励。无定义的活跃指标移除。
- 所有被改动列表区分加载、空结果、加载失败和失效对象。错误提示与页面重试配合，不产生未处理请求拒绝或重复提示轰炸。

### 资料审核与修正

- 管理员有专用的审核详情与受授权文件接口，能检查待审核内容；审核预览不扣积分，不增加普通下载统计，不公开待审文件。
- 本人仅对已驳回资料进行编辑、换文件并重新提交；保留名称、课程、类型、积分、关键词及说明的校验。
- 为资料保留提交版本和审核记录。审核动作针对当前提交版本，重复或过期操作返回状态已变化，不能审过时的文件。
- 采用独立增量迁移；`material` 保持当前内容，增加单调 `revision`，新表 `material_revision` 保存版本快照，`material_audit_log` 保存版本、审核人、动作和原因。迁移为旧资料建立初始版本，不重置原状态或积分。
- 驳回原因必填，最大长度遵守现有数据库约束。重新提交保留原审核历史；上传失败/事务回滚的新增孤立文件可清理，仍被当前版本或历史引用的文件保留。
- 上传奖励仍在首次有效审核通过时发放；修正、重试和重复审核不能重复奖励。普通用户与其他上传者无法读取待审/驳回文件。

### 举报、反馈与兑换

- 资料举报处理需要关联资料入口和处理结论；支持“成立并下架”或“不成立”，保存处理人、原因、时间。用户在现有反馈区域的“我的举报”子页签回看自己的结果，不新建平台通知系统。
- 反馈保留提交、管理员回复、用户回看路径，补齐查询失败和操作状态。
- 管理员订单可查看具体商品、用户和历史状态，并填写处理说明；用户订单可看到领取/交付说明和最终结果。沿用待处理、处理中、已完成、已取消，不引入完整物流。
- 商品说明需准确交代实际兑换方式；演示商品用明确的测试说明。正式商品的真实地点、时段、客服信息不能编造。

## 页面布局方向

| 页面 | 确认后采用的方向 |
| --- | --- |
| 设置 | 上述四分区，统一隐私入口、独立保存语义和真实维护操作 |
| 登录 | 窄屏品牌简化，表单与找回入口优先；桌面保留双栏 |
| 个人中心 | 紧凑身份/积分摘要、少量高频入口、分组记录与服务列表；明确空态 |
| 广场 | 搜索/话题/发布与动态靠前；跨模块入口压缩；关联对象可定位 |
| 首页 | 桌面左右预览保留；窄屏课程点击直接进入详情 |
| 课程 | 搜索和分类优先，低频条件放筛选面板，主操作明确；详情装饰区缩小 |
| 资料 | 文件决策信息、上传状态与修正动作清楚；手机我的上传用摘要卡 |
| 后台 | 待办导向概览、带文字导航、统一筛选分页与详情；手机避免压缩长表格 |
| 其他页面 | 逐页检查真实内容、主次按钮、空/错/忙状态、三主题和返回路径，必要时做同体系调整 |

## 验收与用户决策顺序

1. 用户先确认本设计及实施计划，再开始业务修改。默认由主代理在本会话逐批实施；常规细节按以上规则自主完成，新增大功能或改变产品边界再由用户决定。
2. 完成所有计划内修改及技术验证，准备稳定的独立网页体验环境、学生 A/B、教师和管理员账号、本地测试收件箱及完整体验清单。
3. **停在网页体验节点**。用户实际体验全部页面、主要弹窗和业务流程，标记满意、需调整、希望新增。不能用截图或自动测试代替用户体验结论。
4. 根据用户的体验反馈修正页面或实现用户明确选择的新增范围，再让用户确认受影响的网页体验。
5. 用户确认网页端体验后，由 Codex 进行最终手机端核验；开发期间必要的响应式自测照常进行，但不把正式手机验收提前交给用户。
6. 手机核验后修复移动问题；若影响网页端，则补网页回归并请用户复看受影响部分。最后交付版本、变更和已测/未测记录，部署仍另行决定。

手机核验由 Codex 负责执行自动化、多尺寸、触控、横竖屏、键盘视口、安全区、主题与关键业务核查。可连接并可操作的真机才记真机结果；Chromium/WebKit 的设备模拟、浏览器兼容和实际真机分别记账。当前工具是否能接管真机需在执行时核实；不可接入设备明确标未测，不承诺模拟结果等于 iPhone/Safari 真机通过，也不再把长清单转给用户手工完成。

## 全站网页体验覆盖

体验清单从最终路由、角色和交互生成，至少包含：

- 未登录：登录、注册、找回密码、登录后回跳及无效入口。
- 学生：首页、课程列表/详情/比较/选退课/评价，资料列表/详情/上传/我的上传/驳回修正/下载/收藏/举报，广场发布/搜索/点赞/评论/删除本人内容，通讯录搜索/名片/好友申请处理/解除/隐私，私聊列表/会话/未读/历史，商城/商品/兑换/订单/取消退款。
- 个人区域：个人中心、资料编辑/头像、账号安全/找回邮箱/改密、积分与记录分页、选课、下载、收藏、评价、订单详情、设置全部分区、反馈与举报、帮助、关于。
- 教师：角色资料字段、联系人与课程关联、所允许功能，以及不能访问的管理员入口；共享页面不遗漏角色差异。
- 管理员：概览、课程、资料审核与历史、评价、用户、Banner、广场/评论、商品、订单、反馈、举报，以及前后台切换。
- 跨页：返回保留条件、刷新保持结果、空数据、失败重试、重复点击、权限不足、退出/换号清理。

“已体验”按页面和流程分别记录。用户体验时服务持续可用，直到用户明确结束或安排停止；测试数据的重置只操作隔离实例，先确认用户无需保留当轮体验内容。
