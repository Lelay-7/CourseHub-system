# 账号安全与密码找回 Implementation Plan

> 执行方式：当前会话直接实现；依据用户指定设计，测试优先，完成一次聚焦安全审查。无需真实 SMTP、部署或修改现有数据库。

**Goal:** 实现独立验证找回邮箱、已登录改密、邮件验证码找回及旧凭据失效。

**Architecture:** 独立账号安全控制器/服务，数据库锁保护用户、验证码和限流；邮件发送在事务外，找回统一走有界异步队列。访问与刷新 JWT 都携带数据库凭据版本。

**Tech Stack:** Java 21 / Spring Boot 3.3.5 / MyBatis / MySQL / Vue 3 / Element Plus。

**Spec:** `docs/superpowers/specs/2026-10-09-account-recovery-design.md`

## 约束与审查重点

- 密码 6–20 字符；验证码 6 位、10 分钟、60 秒间隔、5 次错误、账号每小时 5 次、IP 每小时 20 次；绑定额外按待绑定邮箱限流。
- 联系邮箱不迁移为已验证找回邮箱；新增字段仅由安全服务写入且不出现在普通用户序列化中。
- 请求 ID 随机；HMAC 专用密钥；不返回/存储/记录明文验证码；未配置明确报错。
- 公开申请对不存在、禁用、邮箱不匹配及账号限流使用一致反馈；实际匹配查询也在队列中执行。
- 重发、迟到发送、并发消费、错误次数事务提交、更换邮箱后的旧找回码、改密前后登录/刷新竞态、账号切换后的旧前端请求。
